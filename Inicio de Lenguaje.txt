
Crear estructuras de pares de paréntesis.

Crear las estructuras que se requieran entre pares de paréntesis donde puede haber estructuras internas,
llámese pares de paréntesis al par "()".

Ejemplos válidos: ()()()() | (()())(())() | ((())) 
Ejemplos inválidos: ))() | (() | ))((

Léxica:

Definiciones:

+: operador infijo para concatenar ()1 con ()2
in: operador infijo para introducir ()1 en ()2 o operador booleano para el condicional si ()1 esta incluido en ()2
if: condicional para evaluar una condición de pertenencia
else: expresión alternativa si la condición es falsa
=: símbolo de asignación
id: variable para contener resultados de los operadores
n: numero para indicar cuantas capas internas se debe ingresar
print: imprime en pantalla
begin: comienzo del programa
end: fin del programa
def: define una función para reutilizar operaciones de concatenación o inclusión entre estructuras.

TOKEN		PATRON

CONCATENAR	+
ASIGNAR		=
PARENT_ABRE	(
PARENT_CIERRA	)
CONSTANTE	[1-3]
IF		if
ELSE		else
PRINT		print
BEGIN		begin
END		end
DEF		def
IN		in
ID		[a-z]+
SIMBOLO		:


-----------------------------------------------

Sintáctica:

GIC
Prog -> BEGIN ListaSent END 
ListaSent -> Sent ListaSent | Sent 
Sent -> Asig | Impr | Func 
Asig -> ID ASIGNAR Expr 
Impr-> PRINT ID
Func -> DEF ID SIMBOLO Expr' 
Expr -> Expr' | IF ID IN ID SIMBOLO Expr' ELSE SIMBOLO Expr' | PARENT_ABRE PARENT_CIERRA
Expr' -> ID Oper ID 
Oper -> CONCATENAR | IN PARENT_ABRE CONSTANTE PARENT_CIERRA

------------------------------------------------

Semántica:

begin X end -> X

A + B -> AB		// ej: (()) + ()() = (())()()

A in B (en expresión)
A in B ≡ A in(1) B
A in(1) () -> (A)	// ej: () in () -> (())
A in(k) (B) -> (A in(k-1) B)
A in(k) (B C) -> (A in(k) B) C 	// ej: () in(1) ((())) = ((()()))

A in B (en condición)
A in B -> true		// Si la estructura A es subestructura de B
A in B -> false		// Si la estructura A no es subestructura de B
if  A in B : X else: Y 	-> X si A in B
if  A in B : X else: Y 	-> Y si no

def f : S -> guarda S con nombre f
f() -> evalúa S	

V = A  			// Guarda A en V
V 			// Retorna A
print X			// Muestra en pantalla lo que retorna X
// repeat n: X		// Ejecuta X n veces de forma secuencial
